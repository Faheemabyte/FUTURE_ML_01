 Sales & Demand Forecasting System
 
 Future Interns Machine Learning Internship - Task 1

Overview

A Machine Learning system that forecasts business profit based on 
sales, quantity and discount data using multiple ML models compared 
side by side.

 Features
 
- Exploratory Data Analysis (EDA)
- Data visualization with Matplotlib
- Multiple ML models built and compared
- Business insights extracted from data
- Model performance evaluation

Models Used and Results

| Model | Mean Absolute Error |

| Linear Regression | $69.77 |

| Random Forest | $32.60 (WINNER) |

| Gradient Boosting | $38.01 |

| XGBoost | $36.22 |

 Tools and Libraries Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- XGBoost

 Key Business Insights
- Technology has the highest total sales
- West region generates the most revenue
- Higher discounts directly cause lower profits
- Some orders are losing money and need investigation

Dataset
Sample Superstore Dataset from Kaggle
